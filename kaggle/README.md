# Kaggle notebooks

All compute for this project runs on Kaggle, on CPU except the deep-learning baselines (NB06, NB18).
Each folder is one Kaggle kernel: an `.ipynb` plus its `kernel-metadata.json`, all generated by
`python kaggle/build_notebooks.py`. Don't hand-edit the notebooks; edit the builder and regenerate.

Every notebook clones the branch named in `SETUP` in `build_notebooks.py` (currently `feat/implementation`) at run
time, installs the package, runs its tests first, then a sequence of `python -m eegrep <command>` steps.
Push code before you push a kernel.

| Notebooks | What they do |
|---|---|
| NB00 | Test suite and synthetic smoke run |
| NB01 (3 shards), NB02 | Download, fixed preprocessing, feature and graph cache, QC |
| NB03 | Frozen folds, age/sex baseline, classical baselines, PSWE statistics |
| NB04, NB05 | Main 7 × 3 grid, ablations, permutation null |
| NB06 | EEGNet and 1D-CNN baselines (GPU) |
| NB07 | Tables and figures |
| NB09–NB12 | Confirmation folds, matched-training refits, stopping-rule sensitivity, external cohort ds004584, window-length and no-ICA caches |
| NB13–NB23 | Mixed models, PSWE robustness, equivalence tests, learned adjacency, occlusion, severity, adjusted omnibus tests, calibration simulations, out-of-bootstrap comparison |
| NB24–NB26 | Corrected random-graph ablation on a cache rebuilt from OpenNeuro, updated ablation tables, all spatial-cell ablations on that cache |

Push, check and download with the [Kaggle CLI](https://github.com/Kaggle/kaggle-api):

```bash
kaggle kernels push -p kaggle/nb00-setup-tests
```

```bash
kaggle kernels status <owner>/eegrep-nb00-setup-tests
```

```bash
kaggle kernels output <owner>/eegrep-nb00-setup-tests -p kaggle/nb00-setup-tests/output
```

Kernels are private. `OWNER` (environment variable `EEGREP_KAGGLE_OWNER`) is the account that pushes;
`DATA_OWNER` is the account whose outputs NB01–NB22 attach as inputs. A private output can only be attached by
its own account, and the builder warns when a kernel's inputs belong to another account. At most five CPU
sessions run at once per account.
