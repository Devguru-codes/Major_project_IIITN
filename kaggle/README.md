# Kaggle notebooks

All compute for this project runs on Kaggle. The local machine only edits code and commits.
Each folder is a Kaggle kernel: one `.ipynb` plus its `kernel-metadata.json`, all generated by `python kaggle/build_notebooks.py`. Don't hand-edit the notebooks.

| Notebook | Accelerator | What it does |
|---|---|---|
| `nb00-setup-tests` | CPU | Clones the branch, runs `pytest`, runs the synthetic smoke test, writes `environment.json` and `pip_freeze.txt` |
| `nb01-preprocess-s{0,1,2}` | CPU ×3 in parallel | Each shard (every 3rd subject) downloads its raw `.set` files, runs the fixed preamble and builds its feature cache |
| `nb03a-folds-demographics` | CPU | Frozen fold JSON + age/sex confound baseline |
| NB02, NB04+ | see `IMPLEMENTATION_PLAN.md` §2 | NB02 merges the NB01 shards; later phases follow |

Push and run a kernel with the [Kaggle CLI](https://github.com/Kaggle/kaggle-api), using credentials in `~/.kaggle/kaggle.json`:

```bash
kaggle kernels push -p kaggle/nb00-setup-tests
```

Then check its status and download its outputs:

```bash
kaggle kernels status dev123123456/eegrep-nb00-setup-tests
```

```bash
kaggle kernels output dev123123456/eegrep-nb00-setup-tests -p kaggle/nb00-setup-tests/output
```

Kernels are private. Every notebook clones the `feat/implementation` branch at run time, so push code before you push a kernel.
