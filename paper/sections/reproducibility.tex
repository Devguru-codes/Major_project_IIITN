\begin{sloppypar}
The EEG data are OpenNeuro ds004504 (CC0) \cite{ds004504} and ds004584 \cite{ds004584}. Code, configuration
(\texttt{configs/default.yaml}), the frozen fold assignment (\texttt{splits/folds\_ds004504.json},
with the SHA-256 of \texttt{participants.tsv}), every raw training run (one JSON record per run,
with configuration hash, code version, seed and per-subject test predictions), and the Kaggle
notebooks that produced them are available at
\url{https://github.com/Devguru-codes/Major_project_IIITN}. Random seeds are 0--4 for the main grid
(selection folds), 5--9 for the confirmation folds (\texttt{splits/folds\_ds004504\_confirm.json},
committed before any confirmation run), and $10{,}000+i$ and $11{,}000+i$ for permutation $i$ on the
selection and confirmation folds. The main tables and figures are regenerated from the committed raw runs
by \texttt{python -m eegrep report}; the later analyses by the Kaggle notebooks NB10--NB20 (each a sequence of
\texttt{eegrep} commands listed in \texttt{kaggle/build\_notebooks.py}); and every number in the text by
\texttt{paper/make\_numbers.py}, which reads only committed outputs. The resolved package versions are
recorded in \texttt{reports/kaggle\_pip\_freeze.txt}. The full study
runs on free cloud CPUs, except the deep-learning baselines (\gpuHoursTotal{} GPU-hours).
\end{sloppypar}
